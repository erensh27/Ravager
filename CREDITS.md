# Credits

Ravager's handcrafted evaluation and search use published ideas from many
engines, including Stockfish, Komodo, Houdini, Ethereal, Shredder, Rybka,
Gull, Texel, and Andscacs. These are design references; Ravager's engine code
is maintained in this repository.

## Bundled components

- [Pyrrhic](https://github.com/AndyGrant/Pyrrhic), by basil, Jon Dart, and
  Andrew Grant: Syzygy probing. MIT; see [src/tb/LICENSE](src/tb/LICENSE).
- [incbin.h](https://github.com/graphitemaster/incbin), by Dale Weister:
  embedding the neural network. Public domain.
- [Leorik](https://github.com/lithander/Leorik), by Thomas Jahn: bundled NNUE
  network and supported network format. MIT.
- [Zurichess tuner data](https://bitbucket.org/zurichess/tuner): quiet-position
  dataset used to tune the handcrafted evaluation.
- Syzygy tablebase format by Ronald de Man.

Third-party notices and licenses remain with their respective components.
